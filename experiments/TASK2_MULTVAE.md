# Task 2: Mult-VAE augmentation

Multinomial variational autoencoder trained only on the supplied interaction data, including rating-zero events as observed interactions. Encoder: normalized sparse binary history ->128 tanh units ->64-dimensional Gaussian mean/log variance. Reparameterized latent sample ->128 tanh units ->51007-book softmax decoder. Input dropout.5, Adam learning rate.001, batches256; KL weight min(.2,updates/10000). Deterministic posterior mean at inference. NumPy implementation; finite-difference checks cover all parameter blocks (maximum absolute error8.86e-11).

Validation uses the same90/5/5 row split as accepted Task2, with held-out positives explicitly verified absent from VAE training inputs. VAE epoch is selected using only the inner-training portion of the selection cohort; XGBoost count and blend weight use inner validation. Final evaluation is inspected only after selection is locked. The existing16 cached model scores/support signals remain, with two additional per-candidate features: VAE logit and normalized log-probability. Pair design uses differences, sums and absolute differences; mirrored examples stay in the same split. XGBoost predictions are antisymmetrized.

Production VAE refits all provided training interactions for the selected epoch count. Parameters are stored as float16 and reloaded before test scoring. Production XGBoost fits all existing known held-out pairs using original sampled negatives. No external data or pretrained weights are used. Historical cohorts have been reused and sampled negatives may differ from leaderboard negatives. Local improvement does not guarantee public improvement.

Results and checks are recorded in task2_multvae_results.json after the run finishes. Original accepted CSV is preserved. New outputs: /workspace/output/task2_multvae_primary/task_2_predictions.csv and /workspace/output/task2_multvae_blend/task_2_predictions.csv.
