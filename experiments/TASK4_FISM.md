# Task4: time-weighted FISM plus a fresh LightGBM

Accepted public reference entering this experiment: LightGBM with Item2vec, accuracy0.9486, rank57. The preceding Item2vec-XGBoost candidate scored0.9481 and was rejected. This experiment retains the full accepted component bank, including Item2vec, and adds a directly trained history-based model.

## FISM adaptation

FISM represents a reader through shared history-book embeddings A, with a separate target-book embedding B and target bias b. Our score is:

`s(u,i,t) = b_i + [sum_{h in H(u,t), h != i} w_h(t) A_h / sqrt(sum_h w_h(t))] dot B_i`.

Use up to32 known training interactions closest to query time, with `w_h(t)=exp(-abs(t_h-t)/180 days)`. This is a time-weighted, truncated FISM adaptation of recommendation slides169–172, not an unchanged implementation of the original paper. No free reader embedding is used. Pure reader biases are omitted because they cancel between candidate books.

For an observed fitting interaction, exclude its target from the context and contrast it with an unobserved book using pairwise logistic/BPR loss. The same target-excluded context is used for both books in that training pair. Negatives are half uniform-book and half fitting-interaction popularity, rejecting all books already observed for the reader; skip if no negative is found in100 attempts. This avoids labeling another known reading event as an explicit dislike during model fitting.

Use32 factors, initial normal(.0,.03) values, learning rate.025, decay.98 per epoch, sparse L2 coefficient.01, seed937. Cache candidate scores at epochs5/15/30. Each checkpoint contributes four scores: time-weighted score, uniform-nearest-context score, cosine between the weighted history vector and target factor, and a nearest-known-predecessor score. Twelve new scores are appended to the142 accepted component scores, yielding154 candidate signals /308 pair features.

Zero-rated rows remain observed reading events. Numeric ratings are not features. Events with invalid ordering timestamps are omitted from FISM's ordered component; all original component models remain unchanged. Query contexts use only known fitting rows, including known rows after the query date where appropriate for Task4 interpolation. Unknown held-out/test interactions never enter the history.

## Validation and combiner

Reuse the exact fitting/selection/evaluation partition and negatives. The fitting graph excludes all historical holdout targets. Fit validation FISM only on the90% fitting rows; fit test-time FISM on all supplied training rows. Train one fresh LightGBM on71462 historical selection pairs, mirrored to142924 classifier rows, and evaluate on the remaining71463 pairs.

Keep the accepted LightGBM settings fixed:15 leaves, minimum100 examples per leaf,1100 trees, learning rate.035, L2 leaf penalty20, row/column sampling.9, seed619, two CPU threads. No new hyperparameters or blend percentages are selected using evaluation labels. Historical holdouts have been reused across experiments and are not unbiased estimates of final hidden-test accuracy. The new public score is unknown until user submission.

## Checks and reproduction

A finite-difference check reproduces a native BPR parameter update, including history/target vectors and item biases. Independent dense formulas check time weighting, normalization, target exclusion, cosine and predecessor scores. Held-out positives are absent from the fitted graph, query IDs match the accepted bank, final factors replay64 real queries, and the serialized LightGBM reproduces all20000 output decisions. Rows, timestamps, candidate membership, finite margins and candidate-swap antisymmetry are checked.
