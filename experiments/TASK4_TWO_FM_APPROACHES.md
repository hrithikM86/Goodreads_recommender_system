# Task 4: temporal FM and complete component refit

Two experimental prediction files are generated by `task4_two_approaches.py`:

1. `task4_accepted_plus_fm`: the accepted time-aware BPR ensemble (public accuracy 0.9468) plus a temporal FM. Scores are calibrated preference probabilities centered at zero. FM training checkpoints 5/15/30 and nonzero weights .1/.25/.5/.75/1 are compared on inner validation. Also compare against the zero-weight reference; if it is stronger, retain the reference as the recommendation. A nonzero experimental blend is exported so the two requested approaches can actually be compared.
2. `task4_all_models_retrained_fm`: every component is refitted from training interactions in a fresh output directory, then one new CatBoost pair combiner is trained from their predictions. This replaces the old nested blending architecture. It is not an equal average of raw scores, whose scales differ. All components are available to the fresh combiner; it can learn that some are unhelpful.

## Refitted components

- BPR32 and BPR64 from the original ensemble.
- ALS64 and ALS128 from the original ensemble.
- User-period ALS with 180-day and 365-day periods.
- Expanded BPR128 and a separately configured expanded ALS128.
- User-period BPR64 on 365-day windows with offsets 0 and 182 days.
- EASE on the 4,000 most frequent books, penalties 100/500/2000.
- Restricted SLIM with L1 penalties .2 and 2, L2 penalty 10.
- Training-only cosine/Jaccard neighborhoods, calendar activity/KDE, and local-history temporal scores, recomputed from the fitting graph.
- Reader drift and calendar-book bias residuals, trained on the freshly fitted BPR128 factors at checkpoints 3/10/25.
- Temporal FM, a separate independently trained model.
- Original combiner layers are replaced by one newly trained combiner over all component outputs and FM. They are not retained as nested ensemble predictions in approach 2.

The temporal FM uses an exact second-order factorization-machine scoring function with 16 factors. Sparse categorical fields are reader, book, one of 24 calendar intervals (plus invalid-date interval), and reader/coarse-period ID. Calendar boundaries and vocabulary are fit on training data; unknown reader-period IDs are omitted at prediction. It is trained with binary logistic loss on observed interactions and sampled negatives, half uniform-book and half training-popularity. Negative equals positive is rejected. Observed rating-zero interactions are retained, as in the accepted Task 4 model. Numeric rating values are not features.

## Validation and fitting

Reuse the established seed42 random-event split: 90% component fitting, 5% combiner selection, 5% local evaluation. Negative pairs use seed43 and the original training-popularity scheme. Split selection 80/20 with seed17 before mirroring pairs. FM calibration, checkpoint, blend weight, fresh-combiner depth and stopping are chosen using inner validation only. The evaluation partition never trains component models or selects their settings. Full-test component models use all supplied training interactions; the selected combiner uses historical selection labels only. Calendar/query timestamps are valid provided prediction inputs. No test labels, external data, cross-task target matching or opaque-ID decoding are used.

Approach 1 replays the accepted historical model exactly, including its historical preprocessing, and verifies candidate decisions against the accepted CSV. This historical model used in-sample selection predictions for part of its calibration; inherited inner metrics should not be treated as unbiased performance estimates. These local holdouts have also been reused over multiple experiment rounds. Only user-reported leaderboard results establish public-test performance.

## Resource handling

Fresh factor models are fit from scratch, consumed in memory, and mostly not persisted. EASE matrices are likewise used in memory. Query scores, configurations and final combiners are retained. The fresh BPR128 is temporarily saved for fitting the drift residual, then removed after query scoring. Accepted models, original datasets and existing prediction CSVs are preserved. Identical loose dataset copies were removed only after SHA256 equality checks; the complete dataset remains in the repository directory. Rejected reproducible experiment caches were removed to make room, with cleanup manifests under /workspace/work.

## Reproduction

With the existing experiment environment and component data:

```
PYTHONPATH=/workspace/work/task2_packages python experiments/task4_two_approaches.py --mode blend
PYTHONPATH=/workspace/work/task2_packages python experiments/task4_two_approaches.py --mode retrain
python experiments/task4_pair_fm_checks.py
```

The FM kernel is compiled with g++ -O3. Independent checks expand every FM pair interaction explicitly and verify learnability on a synthetic two-book corpus. Export checks verify all 20,000 input rows and candidate choices against saved margins.

## Local results

Accepted historical time-aware BPR ensemble evaluation accuracy: 0.937226256944153. The nonzero FM blend selects epoch30 and FM weight0.1 (accepted weight0.9), inner accuracy0.9399706149863569, evaluation0.9370863243916432. This is slightly weaker locally than retaining the accepted ensemble.

The complete fresh component refit selects a depth6 CatBoost combiner with650 trees, inner accuracy0.9412999370321137 and evaluation accuracy0.9388494745532653. This is a local improvement; public performance is unknown. No other tasks change.
