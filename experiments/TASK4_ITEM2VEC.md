# Task 4: all existing component scores plus Item2Vec

Accepted public reference: LightGBM0.9485. Previous standalone XGBoost scored0.9482; the three-tree blend scored0.9480 and was rejected. This experiment adds a new underlying recommender signal. It does not add a fixed percentage of the accepted model's final prediction.

## Item2Vec

Train a32-dimensional skip-gram model with negative sampling on book-ID sequences ordered by reader and training timestamp. No reviews, book metadata, external data, rating values or ID decoding are used. Zero-rated rows remain reading events; no rating-based filtering occurs. Invalid timestamps are omitted from ordered sequences. Minimum book frequency is2. Books with no eligible contextual training occurrence receive zero vectors/scores.

Training objective for a center book i and nearby book j:

`log sigmoid(E_i dot O_j) + sum_negative log sigmoid(-E_i dot O_negative)`.

Use symmetric dynamic windows with maximum radius5, three negative samples per positive context, and a262144-entry sampled table approximating eligible interaction frequency^.75. Learning rate starts.025 and decays by.95 each epoch. Corpus ordering is deterministic; the random seed is733. Query features are cached at epochs5 and12, and final input/output embeddings are retained.

Each checkpoint supplies12 candidate scores: overall mean and maximum input-vector cosine; closest preceding/following eligible known training-book cosine; previous3/next3 mean cosine; exponentially time-weighted cosine with30/180/730-day bandwidths; mean input-output SGNS dot;180-day-weighted SGNS dot; and closest preceding eligible book's SGNS dot. The candidate itself is excluded from pooled histories. Books after the query timestamp are known fitting-training events, not held-out/test interactions. This is permitted timestamp-conditioned interpolation in Task4, not next-event forecasting.

## Validation

Use the exact established seed42 split and seed43 negatives. Embeddings and histories for historical validation fit only the90% component-fitting rows; all held-out positives are excluded. Query user/book IDs match the earlier baseline caches. Input CSV hashes match the accepted component-bank manifests. Full-test embeddings fit all provided training rows, with no test labels.

## Fresh combiners

Append24 new Item2Vec scores (two checkpoints) to the118 existing component scores, yielding142 candidate signals. Each pair yields142 differences and142 sums. Mirror candidate order for classification training. Reuse the previously selected combiner settings to make the first comparison controlled:

- XGBoost: depth4, minimum child weight20,1553 trees.
- LightGBM:15 leaves, minimum child samples100,1100 trees.
- Both: learning rate.035, L2 leaf regularization20, row/feature sampling.9, seed619, two CPU threads.

Both combiners are newly fitted on71462 historical selection pairs, mirrored to142924 classifier examples. The existing BPR/ALS/time-period/neighborhood/drift/FM components are reused. No new settings, tree counts or blend weights are selected on evaluation labels in this experiment. The remaining71463 historical pairs provide local evaluation. These cohorts have been reused over many experiments, so scores are diagnostics, not unbiased hidden-test estimates.

Two independent prediction files are exported: `task4_item2vec_xgboost/task_4_predictions.csv` and `task4_item2vec_lightgbm/task_4_predictions.csv`. Public scores are unknown until user submission.

## Checks and reproduction

Independent dense calculations verify cosine, time-weighted and SGNS scoring. A synthetic two-sequence corpus verifies that SGNS learns co-occurrence compatibility. Cold vectors score zero. Every held-out positive is absent from fitted histories, and query IDs match the accepted bank. Final embeddings replay64 sampled real test queries. Saved classifier replay, candidate-swap antisymmetry, finite scores, all20000 input row IDs/timestamps and candidate membership are checked before delivery.
